# Evidencias — Entrega 5

- `pruebas-locales.txt`: salida real de la ejecución local de pruebas Node.
- `compose-validacion.txt`: validación estática y datos de verificación local.
- `integracion.txt`: se genera al ejecutar el script contra Docker. Debe indicar
  `Resultado: APROBADA`; una corrida incompleta no acredita el requisito.

No incluir `usuarios.json`, cookies, tokens CSRF, contraseñas ni claves privadas.
Las pruebas con API simulada o clientes PostgreSQL simulados están identificadas
como tales. No son evidencia de una ejecución completa de contenedores.
