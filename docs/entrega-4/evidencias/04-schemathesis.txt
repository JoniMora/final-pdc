# Ejecución: 07/11/2026 20:41 -03 · macOS 13.7.8 · Docker Engine 24.0.2 · Docker Compose version v2.18.1
# Comandos ejecutados desde la carpeta reserva-cupos.

Schemathesis genera solicitudes a partir de contrato/openapi.yaml (casos de cobertura, fuzzing y secuencias con estado siguiendo los links) y verifica cada respuesta: códigos documentados, cabeceras, esquemas, que rechace lo inválido y acepte lo válido. Se ejecuta contra la API detrás de Traefik con un tenant propio, igual que en el CI. La configuración (pruebas/contrato/schemathesis.toml) declara las reglas de negocio documentadas que no son rechazos de datos (409, 422 y el cursor opaco).

$ docker run --rm --network reserva-cupos-infra_publica -v "$PWD/contrato:/contrato:ro" -v "$PWD/pruebas/contrato:/config:ro" schemathesis/schemathesis:4.33.1 --config-file /config/schemathesis.toml run /contrato/openapi.yaml --url http://traefik -H "Authorization: Bearer $CLAVE_CONTRATO" --checks all --max-examples 25 --seed 2026 --generation-with-security-parameters false
