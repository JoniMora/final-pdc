# 08 · Cancelación asíncrona y webhooks firmados de punta a punta (Aula ↔ servicio)
# Ejecución: 09/11/2026 19:57 -03 · macOS 13.7.8 · Docker Engine 24.0.2 · Docker Compose version v2.18.1
# Comandos ejecutados desde la carpeta reserva-cupos.

Aula (http://localhost:3001) es el cliente: llama a la API por el gateway con su cliente derivado del contrato y recibe los webhooks en /webhooks/reservas. La API valida además cada respuesta que devuelve contra el contrato (VALIDAR_RESPUESTAS=true en docker-compose.yml).

## El feed tiene los cambios de estado, no el pedido interno de cancelación
