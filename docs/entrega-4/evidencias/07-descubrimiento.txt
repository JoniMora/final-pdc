# 07 · Descubrimiento de servicios: Traefik encuentra las instancias de la API sin configuración
# Ejecución: 09/11/2026 20:08 -03 · macOS 13.7.8 · Docker Engine 24.0.2 · Docker Compose version v2.18.1
# Comandos ejecutados desde la carpeta reserva-cupos.

Traefik observa Docker (proveedor docker, socket en solo lectura) y registra cada contenedor con la etiqueta traefik.enable. Nadie le indica cuántas instancias hay ni sus direcciones: las descubre, les hace health check en /health cada 5 s y balancea entre las sanas. El panel (puerto 8080) expone lo descubierto en /api/http/services; pruebas/descubrimiento/instancias.sh lo consulta y, con --esperar N, espera a que Traefik tenga N instancias UP (una instancia nueva aparece cuando Docker la marca healthy).

## Una instancia

$ pruebas/descubrimiento/instancias.sh
servicio api@docker: enabled
  http://172.21.0.6:3000 → UP
[código de salida: 0]
