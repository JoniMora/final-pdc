# 07 · Descubrimiento de servicios: Traefik encuentra las instancias de la API sin configuración
# Ejecución: 07/11/2026 20:39 -03 · macOS 13.7.8 · Docker Engine 24.0.2 · Docker Compose version v2.18.1
# Comandos ejecutados desde la carpeta reserva-cupos.

Traefik observa Docker (proveedor docker, socket en solo lectura) y registra cada contenedor con la etiqueta traefik.enable. Nadie le indica cuántas instancias hay ni sus direcciones: las descubre, les hace health check en /health cada 5 s y balancea entre las sanas. El panel (puerto 8080) expone lo descubierto en /api/http/services.

## Una instancia

$ curl -s http://localhost:8080/api/http/services/api@docker | python3 -c 'import json,sys; d=json.load(sys.stdin); print("servicio api@docker:", d["status"]); [print(" ", url, "→", estado) for url, estado in sorted(d["serverStatus"].items())]'
servicio api@docker: enabled
  http://172.31.0.3:3000 → UP
[código de salida: 0]
