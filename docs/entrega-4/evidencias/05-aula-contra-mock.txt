# Comandos ejecutados desde la carpeta reserva-cupos.

Aula usa la API solo a través de contrato/openapi.yaml: su cliente arma cada llamada por operationId y valida cada respuesta. Acá se prueba contra un mock de Prism generado del mismo contrato, sin la API real. Prism responde 422 con la cabecera sl-violations a cualquier solicitud que no cumpla el contrato. Las pruebas del receptor de webhooks usan el vector de prueba del contrato, no el código del notificador.

$ docker run -d --name prism-mock -p 4010:4010 -v "$PWD/contrato:/contrato:ro" stoplight/prism:5 mock -d -m false -h 0.0.0.0 /contrato/openapi.yaml && sleep 6
