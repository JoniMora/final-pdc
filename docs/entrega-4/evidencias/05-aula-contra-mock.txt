Aula usa la API solo a través de contrato/openapi.yaml: su cliente arma cada llamada por operationId y valida cada respuesta. Acá se prueba contra un mock de Prism generado del mismo contrato, sin la API real. Prism responde 422 con la cabecera sl-violations a cualquier solicitud que no cumpla el contrato.
