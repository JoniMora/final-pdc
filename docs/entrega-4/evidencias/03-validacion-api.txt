# 03 · La API valida cada solicitud contra el contrato
# Ejecución: 09/11/2026 19:56 -03 · macOS 13.7.8 · Docker Engine 24.0.2 · Docker Compose version v2.18.1
# Comandos ejecutados desde la carpeta reserva-cupos.

express-openapi-validator usa contrato/openapi.yaml: una solicitud fuera de contrato se rechaza antes de llegar a la ruta.

## Sin clave: 401 (la autenticación va primero)

$ curl -s -w '\nHTTP %{http_code}\n' http://localhost:3000/v1/cambios
{"type":"urn:reserva-cupos:problema:no-autenticado","title":"Clave de API ausente o inválida","status":401}
HTTP 401
[código de salida: 0]

## Identificador que no es un UUID: 400

$ curl -s -w '\nHTTP %{http_code}\n' http://localhost:3000/v1/reservas/no-es-un-uuid -H "Authorization: Bearer $CLAVE_AULA"
{"type":"urn:reserva-cupos:problema:solicitud-invalida","title":"Solicitud inválida","status":400,"detail":"/params/id: must match format \"uuid\""}
HTTP 400
[código de salida: 0]

## Parámetro fuera de rango: 400

$ curl -s -w '\nHTTP %{http_code}\n' 'http://localhost:3000/v1/cambios?limite=900' -H "Authorization: Bearer $CLAVE_AULA"
{"type":"urn:reserva-cupos:problema:solicitud-invalida","title":"Solicitud inválida","status":400,"detail":"/query/limite: must be <= 500"}
HTTP 400
[código de salida: 0]

## Tipo incorrecto en el cuerpo: 400

$ curl -s -w '\nHTTP %{http_code}\n' -X POST http://localhost:3000/v1/actividades -H "Authorization: Bearer $CLAVE_AULA" -H 'Content-Type: application/json' -d '{"nombre":"Redes","capacidad":"diez"}'
{"type":"urn:reserva-cupos:problema:solicitud-invalida","title":"Solicitud inválida","status":400,"detail":"/body/capacidad: must be integer"}
HTTP 400
[código de salida: 0]

## Falta la Idempotency-Key obligatoria: 400

$ curl -s -w '\nHTTP %{http_code}\n' -X POST http://localhost:3000/v1/actividades/019a5f3b-9a10-7f22-8c3d-1e2f3a4b5c6d/reservas -H "Authorization: Bearer $CLAVE_AULA" -H 'Content-Type: application/json' -d '{"participante":"ana"}'
{"type":"urn:reserva-cupos:problema:solicitud-invalida","title":"Solicitud inválida","status":400,"detail":"/headers/idempotency-key: must have required property 'idempotency-key'"}
HTTP 400
[código de salida: 0]
